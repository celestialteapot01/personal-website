PROJECT SUMMARY

ABOUT THE PROJECT

I originally started this project more than five years ago while teaching myself JavaScript.

The idea was to create abrowser game based on operating a followspot. The player uses the mouse to control the position of the spotlight while the stage background moves.

It is an early and unfinished project, so the code reflects what I knew at the time. I have kept it online because it represents an important point in my development and shows where I began.

DEVELOPMENT PLAN

FUTURE DEVELOPMENT

As I continue learning Python and developing my programming skills, I hope to return to the project and expand it further.

Possible future improvements include a scoring system, moving targets, different levels, improved graphics and more realistic followspot controls.
