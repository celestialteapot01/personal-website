PROJECT SUMMARY

ABOUT THE PROJECT

This browser-based utility was developed approximately three years ago to solve a practical maintenance problem within a professional theatre lighting department.

Robe BMFL and MegaPointe fixtures have lamps with a finite operating life. Calculating the remaining lamp life manually for multiple fixtures was repetitive and time-consuming during maintenance periods.

The calculator allows technicians to enter the recorded lamp hours for a fixture and immediately displays the remaining lamp life. It was intentionally designed to be lightweight, quick to use and accessible from any computer with a web browser.

Although relatively small, the project demonstrated how simple software tools can improve efficiency and reduce repetitive calculations in a busy production environment.

FUTURE DEVELOPMENT

FUTURE PLANS

The current calculator focuses on BMFL and MegaPointe fixtures, but it provides a solid foundation for a more comprehensive lighting maintenance application.

Possible future improvements include support for additional fixture types, maintenance scheduling, replacement history, fixture inventories, service records and automated maintenance reminders.

Revisiting this project as I move towards Python would allow me to expand it and create something more feature rich.
